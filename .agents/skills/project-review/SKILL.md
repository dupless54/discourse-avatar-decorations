# Review
Inspect locked task, rules, exact diff/source/assets, and available evidence yourself. Check scope, correctness, public-data/privacy, injection/XSS/CSS/URL risks, Discourse compatibility, UI regressions, and meaningful test gaps. Return APPROVE, REJECT, or NEEDS_HUMAN with evidence.
